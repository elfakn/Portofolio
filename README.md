# Elfa Khoirun Nissa — Fullstack Developer Portfolio

Personal portfolio showcasing skills, experience, and projects. Built with Vue 3, Vite, and Tailwind CSS.

## About

I'm a Fullstack Developer based in Indonesia. I build web apps from backend to frontend — mostly Vue, Laravel, and a lot of debugging in between. I usually work on internal tools and web apps that need to be reliable, not fancy.

## Tech Stack

- **Frontend:** Vue 3 (Composition API, `<script setup>`), Tailwind CSS, Vite
- **Backend:** Laravel, Spring Boot, .NET Core, CodeIgniter, ZKoss
- **Databases:** PostgreSQL, MySQL, SQL Server, Oracle
- **Tools:** Git, VS Code, Figma, Postman, REST API

## Features

- Responsive design (mobile, tablet, desktop)
- Dark mode with system preference detection and manual toggle
- Smooth scroll navigation with IntersectionObserver scroll-spy
- Accessible components (skip-link, ARIA attributes, focus-visible)
- Tabbed Experience & Projects section
- Contact links (Email, WhatsApp, LinkedIn, GitHub)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
